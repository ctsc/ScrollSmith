# @scrollsmith/mcp

The Scrollsmith MCP server. Stateless Streamable HTTP, no auth, no model calls:
it serves skills (instructions, templates, helper recipes) that the user's own
AI assistant executes. Built on `@modelcontextprotocol/server` v2.

- Public endpoint: `https://mcp.scroll-smith.com/mcp`
- Keyed endpoint: `https://mcp.scroll-smith.com/mcp/<install_key>` - the website mints an
  anonymous `k_…` key per visitor and shows this URL; the key is logged on every
  `initialize` / tool call (`mcp_events.install_key`) so distinct installs can be counted.
  Plain `/mcp` keeps working (logged with a null key).
- Tools: `scrollsmith_status`, `list_skills`, `search_skills`, `get_skill`, `get_skill_file`, `get_schema`, `get_registry`, `get_rulebook`, `get_style_pack`, `get_asset_sources`, `get_recipe`
- Resources: `skills://<id>`, `schemas://<id>`, `decisions://<category>`, `rulebook://<format>`, `style-packs://<id>`, `layouts://index`, `hooks://taxonomy`, `platforms://presets`, `asset-sources://<kind>`, `recipes://<id>`, `toolkit://manifest`, `toolkit://<path>`
- Prompts: the 11 `recipe_*` prompts in `recipes/`
- The server is skills-only: it serves instructions, schemas, the editing-decision registry, rulebooks, style packs, asset-source guidance and local toolkit scripts. It never calls a model, renders video, uploads footage or holds provider keys; the user's own assistant runs everything locally.
- Content comes from `content/bundle.json`, generated by `pnpm content:build` from `skills/`, `rulebooks/`, `recipes/`, `packages/toolkit/` and `packages/packs/`. `pnpm lint` fails when the bundle is stale.

## Local

```bash
pnpm --filter @scrollsmith/mcp dev     # http://127.0.0.1:3001/mcp
pnpm --filter @scrollsmith/mcp typecheck
```

Smoke test with the MCP Inspector: `npx @modelcontextprotocol/inspector`, transport
"Streamable HTTP", URL above.

## Deploy (Vercel)

1. Vercel → Add New Project → import `ctsc/ScrollSmith` again → name `scrollsmith-mcp`.
2. Root Directory: `apps/mcp`. Framework preset: Other. No build command needed.
3. Deploy. Then Settings → Domains → add `mcp.scroll-smith.com`
   (GoDaddy: CNAME `mcp` → `cname.vercel-dns.com`).
4. Env vars (Settings → Environment Variables): `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`
   (same values as the web project) so `initialize` / tool calls land in `mcp_events`.
   Without them tracking is a silent no-op.
5. Add any extra hostname to `PUBLIC_HOSTS` in `src/server.ts` (Host header allow-list).
